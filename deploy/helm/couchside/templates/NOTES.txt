Couchside is starting.
{{ if .Values.ingress.enabled }}
Open: http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}
Port-forward to try it:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "couchside.fullname" . }} 8080:{{ .Values.service.port }}
  open http://localhost:8080
{{- end }}

Then add libraries under {{ .Values.media.mountPath }} on the Libraries page.
Titles, posters and backdrops come from TMDB{{ if not .Values.tmdb.enabled }} (turned off: tmdb.enabled is false){{ end }}.
{{- if .Values.auth.enabled }}

Passwords are required (auth.enabled). If no admin has one yet, the log
prints a one-time setup code:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "couchside.fullname" . }} | grep -i "setup code"
{{- else }}

Sign-in is passwordless at first: pick a profile. Until the first run is
done, a browser outside your home network needs the setup code from the log.
Before putting Couchside on the internet, set auth.enabled=true, give every
account a password and serve it over HTTPS (docs/install.md).
{{- if .Values.ingress.enabled }}

WARNING: this ingress allows passwordless sign-in (auth.allowOpenIngress).
Anyone who can open {{ .Values.ingress.host }} can pick a profile.
{{- end }}
{{- end }}

Lost the admin password?
  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "couchside.fullname" . }} -- couchside reset-password -admin <name>
{{- if and .Values.livetv.hdhomerun (not .Values.persistence.recordings.enabled) }}

Live TV is on but persistence.recordings isn't: recordings go to the
container and are lost on restart. Enable it, or pick a folder under a
writable {{ .Values.media.mountPath }} (media.readOnly=false) in Settings.
{{- end }}
