Couchside

Support

Couchside is a media server you run yourself, and the Roku app plays what's on it. There's no Couchside account or subscription: you need a Couchside server on your own computer or network first. The install guide shows how to set one up.

Getting help

  • Email: support@couchside.com.
  • Problems and questions: GitHub issues. Say which app (Roku or web), its version (on the Roku, it is shown in Settings), and what you did when it went wrong.
  • Security problems: report them privately, not in a public issue.
  • Documentation: the docs on GitHub cover libraries, playback, live TV and accounts.

Connecting your Roku

  1. Install Couchside from the Roku Streaming Store and open it.
  2. Servers on the same network are listed by name. Pick yours, or choose to enter an address and type it, for example 192.168.1.20:8080 (no http:// needed).
  3. Pick your profile. A profile with a password asks for it.

The Roku remembers the server and the profile. If the server moves to a new address on your network, the Roku finds it again when it starts.

Common problems

My server isn't listed

  • The Roku and the server must be on the same network.
  • In Docker, discovery needs --network host; on Kubernetes, discovery.hostNetwork=true. Without it, type the address instead.
  • Check the address works in a browser on another device first.

I can't sign in

  • Names and passwords are the ones on your Couchside server; ask whoever runs it.
  • After too many wrong tries, wait a few minutes before trying again.
  • A temporary password has to be changed in the web app before the Roku can use it.

A video won't play, or keeps stopping

  • Files the Roku can't play directly are converted by your server, which takes more of its power. A slow server or network can stall them.
  • Make sure the server is running and can reach its media files.
  • Subtitles from a large file can take a while the first time: the server prepares the whole track.

I was signed out

Someone may have signed this Roku out from the server's Settings page, or changed the profile's password. Pick the profile and sign in again.

Privacy

The Roku app talks only to your own server. See the privacy policy.
